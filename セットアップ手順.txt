銅建値アプリ（スマホ版）　セットアップ手順
==================================================

しくみ
・GitHub（無料）が平日 8〜19時に30分ごとにJX金属のページを確認します。
・建値はスマホのホーム画面に置いたアイコンから見られます（iPhone・Android 共通）。
・改定があると、無料の通知アプリ「ntfy」で全員のスマホに通知が届きます。
・あなたのPCやサーバーを動かしておく必要はありません。費用もかかりません。


■ A. GitHub の準備（のばやしさんが1回だけ。パソコンで作業）
--------------------------------------------------
1. https://github.com/signup で無料アカウントを作ります。
   ユーザー名がアプリのアドレスの一部になります（例：nobayashi → nobayashi.github.io）。

2. 右上の「＋」→「New repository」
   ・Repository name：cuprice
   ・「Public」を選ぶ（無料で画面を公開するために必要です）
   ・それ以外はそのままで「Create repository」

3. できた画面の「uploading an existing file」をクリックし、
   この zip を展開した「cuprice」フォルダの【中身すべて】
   （.github、docs、scripts、README.md、この手順書）をまとめてドラッグします。
   ※「.github」フォルダも必ず含めてください。これが自動確認の設定です。
   → 下の「Commit changes」を押します。

4. 上の「Settings」→ 左の「Pages」
   ・Source：「Deploy from a branch」
   ・Branch：「main」と「/docs」を選んで「Save」
   1〜2分後、画面上部に公開アドレスが出ます：
     https://（ユーザー名）.github.io/cuprice/

5. 上の「Actions」→ 確認が出たら「I understand my workflows, go ahead and enable them」
   → 左の「銅建値チェック」→ 右の「Run workflow」→ 緑の「Run workflow」
   1分ほどで緑のチェックが付けば成功です（テスト通知も送られます）。


■ B. 各自のスマホで（全員それぞれ）
--------------------------------------------------
1. 公開アドレス（https://（ユーザー名）.github.io/cuprice/）を開きます。
   LINE やメールでアドレスを送っておくと簡単です。
   ・iPhone：Safari で開く → 共有ボタン（□に↑）→「ホーム画面に追加」
   ・Android：Chrome で開く → 右上の︙ →「ホーム画面に追加」または「アプリをインストール」

2. 通知アプリ「ntfy」を入れます（App Store／Google Play で「ntfy」と検索、無料）。

3. ntfy を開いて「＋」をタップし、トピック名に次を入れて購読します。
      cuprice-ib2y9a9nbbof
   （アプリの画面下部にもコピーボタン付きで表示されています）
   iPhone は通知の許可を求められたら「許可」を押します。

4. 動作確認：A-5 の「Run workflow」をもう一度押すと、全員にテスト通知が届きます。


■ ふだんの動き
--------------------------------------------------
・建値が改定されると「銅建値 2,390,000円/t（▲50,000）」のような通知が届きます。
  通知をタップするとアプリが開きます。
・アプリは開くたびに最新の情報を読み込みます。右上の ↻ でも更新できます。
・電波がないときは、前回読み込んだ建値を表示します。


■ 困ったとき
--------------------------------------------------
・通知が来ない／建値が古い：GitHub の「Actions」を開き、赤い×が付いていないか確認します。
  赤い×が続くときは、JX金属のページのつくりが変わった可能性があります。
  失敗するとGitHubから登録メールアドレスにお知らせメールが届きます。
・「Actions」で失敗理由に「Permission」「403」と出る場合：
  Settings → Actions → General → 一番下の Workflow permissions を
  「Read and write permissions」にして Save し、もう一度 Run workflow を押します。
・長期間（60日）改定がないと GitHub が自動確認を止めることがあります。
  その場合は「Actions」→「銅建値チェック」の「Enable workflow」を押します。
・トピック名を知っている人は誰でも通知を受け取れます。社外の人に知られて困る場合は、
  docs/config.json の ntfyTopic を別の名前に変えて、全員が登録し直してください。
